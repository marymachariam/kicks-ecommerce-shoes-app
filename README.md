# Kicks - E-commerce Shoes App

A modern **Flutter** e-commerce application for buying shoes.

## Features

- Beautiful and responsive UI
- Product listing & details
- Authentication (Login / Sign up)
- Provider for state management
- Clean architecture with ViewModels

## Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Provider
- **Architecture**: MVVM (View + ViewModel)

## Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Android Studio / VS Code
- An emulator or physical device

### Installation

```bash
# Clone the repository
git clone https://github.com/marymachariam/kicks-ecommerce-shoes-app.git
cd kicks-ecommerce-shoes-app

# Get dependencies
flutter pub get

# Run the app
flutter run
```
